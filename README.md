# ♞ Chess AI — Шахматная платформа на React + Vite + Tailwind CSS

Современное веб-приложение для игры в шахматы с умным ботом, набором тактических задач, кастомизацией оформления и звуковыми эффектами.

## ✨ Возможности

### 1. Шахматная логика и валидация
- Полная поддержка всех шахматных правил через `chess.js`:
  - Рокировка (короткая и длинная)
  - Взятие на проходе (en passant)
  - Превращение пешки (Queen, Rook, Bishop, Knight) с диалоговым окном выбора
  - Определение шаха, мата, пата, троекратного повторения и ничьи по недостатку материала
- Интерактивная доска через `react-chessboard` с поддержкой:
  - Drag-and-drop перетаскивания фигур
  - Click-to-move (клик на фигуру -> клик на поле назначения)
  - Подсветки последнего хода и шаха королю
  - Подсветки доступных ходов с точками-подсказками

### 2. Режимы игры
- **Игра с ботом:**
  - 3 уровня сложности:
    - *Новичок*: Случайные ходы с базовым взятием свободных фигур
    - *Любитель*: Позиционная оценка по таблицам полей (PST)
    - *Мастер*: Алгоритм Minimax с Alpha-Beta отсечением глубиной 3 полухода
  - Динамический индикатор обдумывания хода ботом
  - Оценка баланса позиции в реальном времени
- **Шахматные задачи (Puzzles):**
  - Подборка тактических позиций (Мат в 1 ход, Мат в 2 хода, Оперный мат Пола Морфи, Королевская вилка, Связка)
  - Автоматический ответ противника на верные многоходовые ходы
  - Проверка правильности, кнопка текстовой подсказки, счётчик решённых задач
  - Взрыв конфетти (`canvas-confetti`) при решении задачи
- **Режим вдвоём (Pass & Play):**
  - Локальная игра двух игроков за одним экраном

### 3. Кастомизация
- 6 тем оформления доски:
  - Классическая (Classic Green)
  - Деревянная (Warm Wood)
  - Кибер Неон (Cyber Neon)
  - Океан (Ocean Blue)
  - Полночь (Midnight Purple)
  - Изумрудная (Emerald)
- Разворот доски (Flip board) на 180°
- Включение/выключение точек возможных ходов

### 4. Звуковые эффекты и анимации
- Реализованы через синтез **Web Audio API** (не требует загрузки внешних аудиофайлов):
  - Звук обычного хода (деревянный щелчок)
  - Звук взятия фигуры (хлёсткий удар)
  - Звук рокировки (двойной стук)
  - Звук шаха (гармоничный колокольчик)
  - Звук победы (мажорное арпеджио)
  - Звук ошибки при неверном ходе в задачах

## 🚀 Запуск проекта

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере: `http://localhost:5173/`

### Сборка production-версии
```bash
npm run build
```

## 🛠 Стек технологий
- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **chess.js** — логика и правила шахмат
- **react-chessboard** — визуализация доски
- **lucide-react** — векторные иконки интерфейса
- **canvas-confetti** — анимация праздничного конфетти
- **Web Audio API** — встроенный звуковой движок
